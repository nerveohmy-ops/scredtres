# SCREDTRES // Telegram Mini App (Frontend)

Монохромный (ч/б), исключительно темный интерфейс интернет-магазина одежды для бренда **SCREDTRES**, оптимизированный под Telegram Mini App (TMA).

## 🏴 Особенности и дизайн
- **Эстетика**: Строгий черно-белый стиль (Jet Black / White / Grayscale), бруталистская типографика, вампирский логотип SCRED с клыками.
- **Dark Theme Only**: Никаких светлых тем — глубокий черный фон (`#000000`), карточки `#090909`, четкие контрастные границы.
- **Интеграция с Telegram WebApp SDK**:
  - Автоматическая адаптация Safe Area (отступы под шторку Telegram на iOS и Android).
  - Установка цветов заголовка и фона (`#000000`).
  - Тактильный отклик (Haptic Feedback) на клики, выбор размера, добавление в корзину и оформление.
  - Автозаполнение данных пользователя (`initDataUnsafe.user`).
  - Передача оформленного заказа боту через `Telegram.WebApp.sendData`.
- **Функционал магазина**:
  - Каталог с фильтрацией по категориям (Худи & Зип, Футболки, Штаны, Куртки, Аксессуары).
  - Поиск и сортировка (популярность, цена, рейтинг).
  - Детальная карточка товара (галерея, оверсайз размерная сетка, спецификация 520+ GSM).
  - Корзина с расчетом доставки (бесплатно от 15 000 ₽) и промокодами (`SCRED`, `OPIUM`, `VAMP10`).
  - Оформление заказа (СДЭК ПВЗ/курьер, Почта, оплата СБП/карта/Stars/USDT).
  - Эдиториал-лукбук (Lookbook) с возможностью купить образ в один клик.
  - Избранное (Wishlist) и личный кабинет с историей заказов и FAQ.

## ⚡ Быстрый запуск

### Вариант 1. Через bat-файл
Дважды кликните по файлу **`Запустить_SCREDTRES.bat`** в папке проекта.

### Вариант 2. Через терминал
```bash
# Режим разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## 🤖 Подключение к Telegram Bot

1. Задеплойте папку `dist` (или репозиторий) на любой бесплатный HTTPS-хостинг (например, [Vercel](https://vercel.com), [Cloudflare Pages](https://pages.cloudflare.com) или [GitHub Pages](https://pages.github.com)).
2. Откройте [@BotFather](https://t.me/BotFather) в Telegram:
   - Введите команду `/newapp`
   - Выберите вашего бота
   - Введите название приложения: `SCREDTRES`
   - Введите короткое описание
   - Загрузите изображение логотипа (файл `public/logo.jpg`)
   - Укажите HTTPS-ссылку на ваше задеплоенное веб-приложение
   - Задайте короткое имя (short name), например: `shop`
3. Готово! Ссылка на приложение будет иметь вид: `https://t.me/<ваш_бот>/shop`.
